#  Einführung eines Dark Mode für App und Web

## Thema

Umschaltbarer Dark Mode für mobile App und Web-Anwendung

## Zusammenfassung

            Einführung eines nutzerseitig umschaltbaren Dark Mode für App und Web, inklusive automatischer Umschaltung basierend auf Systemeinstellungen.


## Kernaussagen

- Deutlicher Anstieg der Kundenanfragen nach Dark Mode in Support-Tickets und App-Store-Bewertungen
- Theme-System auf Basis von Design-Tokens geplant, zunächst für Kernbildschirme (Dashboard, Zahlungen, Profil)
- Umschaltung manuell über Einstellungen sowie automatisch über Systemeinstellung
- Zwei von drei Hauptkonkurrenten bieten bereits Dark Mode an
