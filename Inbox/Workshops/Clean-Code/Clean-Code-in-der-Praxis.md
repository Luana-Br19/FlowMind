#  Clean Code in der Praxis

## Thema

Vermittlung praxisnaher Clean-Code-Prinzipien und Analyse der eigenen Codebasis


## Kernaussagen

- Kent Becks vier Regeln für einfachen Code: Tests bestehen, Absicht klar ausdrücken, keine Duplikation, minimale Elemente
- Funktionsnamen sollten ein Verb enthalten und eine einzige klar erkennbare Aufgabe beschreiben
- Faustregel: eine Funktion sollte auf einen Bildschirm passen
- Generische catch(Exception e)-Blöcke vermeiden, spezifische Exception-Typen verwenden
- Fail-Fast-Prinzip bei Fehlerbehandlung anwenden
